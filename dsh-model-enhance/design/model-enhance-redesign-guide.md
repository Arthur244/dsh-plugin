# 模型资料增强 · 视觉重设计预览说明

## 文件用途

本说明与 `model-enhance-redesign.html` 配套使用。

HTML 文件是 **dsh-model-enhance 插件设置界面的独立视觉与交互预览**，用于确认页面结构、信息层级和视觉效果，不会读取或写入真实模型配置，也未修改插件现有代码。

## 打开与查看

直接用浏览器或 WorkBuddy 预览面板打开 `model-enhance-redesign.html`。

页面顶部的状态切换栏仅用于演示，可快速切换以下状态：

| 状态 | 展示内容 |
| --- | --- |
| 初始设置 | 选择目标服务商、原厂资料来源，并进入模型匹配 |
| 匹配结果 | 搜索已添加模型，查看匹配状态并进入推荐详情 |
| 无变更 | 当前配置与推荐一致，不需要写入 |
| 待确认应用 | 对比当前值与建议值，确认影响后模拟应用 |
| 保存完成 | 展示保存、字段核对和后续注意事项 |

也可以通过 URL 锚点直接打开对应状态，例如：

```text
model-enhance-redesign.html#results
model-enhance-redesign.html#nochange
model-enhance-redesign.html#changes
model-enhance-redesign.html#saved
```

## 可体验的交互

- **初始设置**：选择目标服务商后，匹配按钮变为可用；点击进入匹配结果。
- **匹配结果**：可按模型 ID 或名称筛选；点击模型卡片进入对应详情。
- **推荐详情**：可切换“允许替换已有字段”，或模拟重新生成预览。
- **待确认应用**：勾选确认项后，应用按钮变为可用；点击进入保存完成状态。
- **未匹配详情**：选择明确候选前，不生成配置建议。
- **原生页面区域**：模型提供商、打开配置文件、关闭等按钮仅用于呈现视觉上下文，不执行真实操作。

## 设计调整重点

### 1. 与原生设置页保持一致

沿用原生模型设置页的深色表面、细描边、卡片圆角、紧凑按钮和状态点，避免插件区域看起来像独立于宿主的另一套界面。

### 2. 收拢说明文字

内置资料数量、来源和生成时间合并为元信息栏；较长的资料来源与注入规则放入可展开区域，减少首屏文字压力。

### 3. 明确操作流程

通过“选择服务商 → 匹配模型 → 预览并应用”步骤条表达当前阶段。该步骤条属于正式业务界面的设计提案，与顶部的预览状态切换栏用途不同。

### 4. 提升模型列表可读性

模型名称、模型 ID、匹配状态和查看入口分层排列；已匹配、未匹配等待状态使用独立标签，不再挤在同一段文本中。

### 5. 强化变更核对

候选资料、图片输入能力、覆盖选项和配置预览分别分区。当前值与建议值采用双栏对照，移除的 `off` 档位单独标注；需要覆盖字段时，确认项与应用按钮放在同一操作区域。

## 哪些内容只属于预览

以下元素用于展示和导航，**不属于建议落地的正式插件界面**：

- 最上方的“模型资料增强 · 视觉重设计”预览标题栏。
- “初始设置 / 匹配结果 / 无变更 / 待确认应用 / 保存完成”状态切换栏。
- 页面底部的预览说明。
- 模拟操作提示 Toast。
- 原生模型提供商列表仅为页面上下文示意，不包含真实功能。

窄预览面板中，顶部状态切换栏可能出现横向滚动条；它仅用于演示导航，不是正式业务页面的横向滚动需求。

## 后续落地边界

若后续确认采用此设计，再将视觉方案映射到 `dsh-model-enhance/client.js`：

- 正式界面只保留模型资料增强业务面板，不引入预览导航。
- 颜色、圆角和焦点状态应优先映射为 DSH 的 `--dsw-alias-*` 主题变量，而非直接使用预览中的固定色值。
- 保留现有的受控预览、覆盖确认、阻止应用和一次性写入逻辑。
- 本次交付不包含上述代码改动。
